SOMEONE ONCE SAID
常驻 AGENT · 后端实现04 / 09
可靠性

事件不会丢，
它只是在状态机里换一行

  create table inbox (
    id         bigserial primary key,
    source_id  text      not null,     -- 去重键
    status     text      not null default 'pending',
    attempts   int       not null default 0,
    unique (user_id, source, source_id)
  );
取事件时加租约，运行结束才改成 done；租约过期，接替者能取走同一条，attempts +1 后按退避重试。运行中又收到事件时，先选定一种策略：留给下次、并入当前，或中断重来。
