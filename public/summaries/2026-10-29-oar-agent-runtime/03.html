02 / 生命周期以 Codex 为例

一项任务，
从启动到收尾

先选运行时并打开会话，再发任务、观察结果，最后释放资源。

1
选择 Runtime

从注册表取出 Codex 对应的运行时实现。

2
确认安装可用

调用 installation()；只有返回 available 才继续。

3
打开 Session

传入安装结果与工作目录；订阅事件以观察过程。

4
发送任务并等待本轮结果

promptAndWait() 将输入关联到对应 Turn；事件可同时流向界面。

5
读取结果，释放会话

检查完成或拒绝结果；不再使用时调用 dispose()。

TypeScript 调用示例省略 import；直接使用 process.cwd()
const runtime = defaultRuntimes.require("codex") const found = await runtime.installation?.() if (found?.kind !== "available") throw Error("Codex unavailable") const session = await runtime.session(found, { cwd: process.cwd() }) try { await promptAndWait(session, "修复问题") } finally { await session.dispose() }
两个时间点Turn 结束：本轮有结果 · dispose()：释放会话资源

依据：@botiverse/oar README 的使用示例。
