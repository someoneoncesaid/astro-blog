OAR 到底
统一了什么？
OAR 是一个 TypeScript 库。它用共同的 Runtime / Session 接口，让应用启动、控制并观察不同的编程 Agent。

01
运行前：知道能不能用
检查 Agent 是否已安装；按运行时查询模型、登录和用量等可用信息。
02
运行中：用同一套会话接口
创建 Session、发送任务；可用的排队、转向和取消能力由运行时声明。
03
运行后：读统一事件与原始记录
用 events() 展示过程；用 records() / rawEvents() 核对原生消息。
