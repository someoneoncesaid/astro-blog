RC.5 · WEB SEARCH 默认行为变化

搜索默认，跟着模型走

没配 searchProvider 时，搜索由发起请求的模型决定：DeepSeek 模型走服务端搜索，其他模型走 Search API。

之前
searchProvider:
deepseek-search-api
所有搜索都走独立检索接口
现在
不固定
按模型路由选择
DeepSeek 模型走服务端搜索
模型请求路由
搜索提供方
deepseek-official
deepseek-account
DeepSeek 服务端搜索deepseek-official · Messages
其他路由
未在模型请求中
DeepSeek Search APIdeepseek-search-api · 独立检索
为什么这么选
—服务端搜索不按次收费，成本是这次 turn 的 token 与延迟
—Search API 独立检索：低延迟、按次计费

只影响没显式配置 searchProvider 的部署；手动固定后行为不变。
