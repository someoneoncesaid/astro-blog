FIX · #8634 约 14 行 + 测试重构
spawn 时补上 Host 的 Node 模式
// 仅当 Host 自己带着这个变量时才补
env: { ...workerNodeModeEnv(process.env) }
Electron 的 Node 模式只认环境变量，不认二进制名。
纯 Node Host 没有该变量，环境不变。
→ worker 以 Node 模式启动，share 正常注册
