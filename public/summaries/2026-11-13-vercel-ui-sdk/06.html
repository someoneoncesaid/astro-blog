组件不用你写，
问你的 Agent

官网原话：You don't. Ask your agent. Agent 自己挑行为、在你的框架里组装。这个仓库本身也是「Agent 原生」的：

Skills 随 npm 包分发
npx skills add vercel-labs/ui --skill ui-sdk
装上技能，Agent 就会照 agent-ready / patterns / testing 的规范写 UI。
每个框架配一名「专家」
.agents/experts/ 五个框架各一份：是谁、懂什么、已定下哪些决策（expert / knowledge / decisions），可被 Claude Code 加载为子代理。
约束面向「模型一次写对」
零运行时依赖 · SSR / 水合前可用 · RTL 不用 provider · 弹层不依赖 portal · API 形状跨组件跨框架一致。目的：让模型用最少的 token 写对。
