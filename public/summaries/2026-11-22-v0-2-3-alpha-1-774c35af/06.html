PTC 默认改为持久执行

省略 executionMode 时，Node PTC 的默认行为发生变化。

原默认

每次调用启动新进程

使用 per-call 时，脚本可以用顶层 return value 返回结果。

新默认

同一 Agent 复用 Node 进程

顶层变量可在后续调用中继续访问，最后一条表达式作为返回值。

旧脚本可把 return value 改成末尾表达式，或显式设为 per-call。workflow-ptc 也适用。

来源　PTC 升级指南 · PR #8848
