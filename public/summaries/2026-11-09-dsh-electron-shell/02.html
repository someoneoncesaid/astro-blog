进程结构

双击图标后，谁在运行？

进程链
Electron 可执行文件直接当 Node 用，应用不依赖系统 Node.js 或 pnpm；--port 0 由操作系统分配端口，避开 Web 默认的 3080。
关键细节
桌面专用配置。Electron 用名为 desktop 的 profile 启动后台，对应 $DSH_HOME/profiles/desktop。公开 CLI 会拒绝用这个 profile 启动，避免两边同时使用这份配置。
运行时校验：isDesktopHostEvent 逐条守卫生命周期消息；协议外事件直接 SIGTERM（plugin-operation 诊断事件先单独分流）。
后台启动失败时，提示和诊断分开
用户提示在弹窗里，说明启动出了什么问题。
排查详情在崩溃报告里。报告写入后，弹窗会显示路径。Host 上报的完整错误链在 hostDiagnostic，异常退出时捕获到的 stderr 尾部附在退出错误里。
