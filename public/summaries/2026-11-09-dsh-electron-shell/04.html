加载页怎么进入应用？

Web 靠服务端渲染 index.html 时注入一套行表；桌面没有服务端，但同一个文档最终要完成同样的注入。
行表是纯 JSON：浏览器版渲染进 HTML、表尾带结算脚本；桌面版经 IPC 发走、不含结算脚本，由页面执行完后自己 resolve。只有 script-src 行等 onload，script-preload 跳过；任一行失败则 gate rejected，走原生恢复。
await globalThis.__DSH_BOOT_READY__?.promise
boot kernel 的第一行：安静地等。全局不存在，说明这份文档没有 bootstrap 负责。
boot 分岔只有 apps/web/src/main.ts 一处；其余差异是「能力在不在」的探测，不是判断载体。
streamBaseUrl 必须显式传：页面 baseURI 是 dsh-app:// 域，从那里解析不出 ws://127.0.0.1:<port>。
