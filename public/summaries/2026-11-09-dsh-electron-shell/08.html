Electron 和 Web 各管什么？

07 · 环境差异　登录 shell 探测（<shell> -ilc 读 env -0，失败依次 /bin/zsh → /bin/bash → /bin/sh，Windows 跳过这一步）· 语言缓存 locale-cache · 平台窗口（macOS 关窗隐藏保活，Windows 托盘 + 首次确认）。都实现在 Electron 内，不下沉到页面。
1
复用，不复制
凡 Web 已有的——认证、路由、流、插件管理、boot 页——一律复用；桌面专属代码只出现在接触面。代价是桌面仍监听一个本地端口，收益是 Web 行为升级随同一版本发布，桌面不用另写一遍。
2
同一文档内引导
桌面和 Web 跑在同一个 index.html，差异在 boot gate 结算之前的注入阶段消除；__DSH_BOOT_READY__ 是唯一同步点。
3
能力探测降级，而非条件编译
桌面桥是可选全局，客户端逐点探测，探测为空即回退 Web 行为——同一份 client 代码维持两种运行态。
界面随空间适配，壳随平台适配。
