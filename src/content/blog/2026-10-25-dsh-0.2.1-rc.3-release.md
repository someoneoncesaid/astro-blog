> rc.3 带来四项变化：模型列表自动更新、三个区域新增 More 菜单、新会话复用未开始的空白会话，以及桌面端行为统计补充。

本说明整理 `dsh-v0.2.1-rc.2` 到 `dsh-v0.2.1-rc.3` 的用户可见变化。升级不需要更改命令行用法，也不需要额外配置。

## 模型列表自动更新

![xhs-01-models](/posts/2026-10-25-dsh-0.2.1-rc.3-release/assets/88f511cb4bec.png)

API Key 是连接 DeepSeek 的访问凭证。使用它连接时，只要服务地址仍是 DeepSeek 官方地址 `https://api.deepseek.com`，且你没有自定义模型列表，应用就会从官方模型服务更新可选模型。自定义过服务地址或模型列表时，应用会保留你的设置。

第一次读取最多等待 5 秒；读取过的列表可使用 10 分钟，过期后在后台更新。如果网络请求失败，会继续使用上次读到的列表；还没有缓存时，则使用应用自带的列表。

> **注意：升级后检查模型列表**
> 如果你保存的模型列表与 rc.3 自带列表不完全相同（包括顺序），应用会把它当作自定义列表，停止自动跟随官方更新。要恢复自动更新，请在模型设置里选择 **Restore defaults**。

此外，内置的 DeepSeek Flash 和 V4 Pro 每次可参考的上下文长度都更新为 1,048,576 tokens（模型处理文本的计量单位）。另外两处边缘情况也已修复：模型服务未提供提示词更新设置时，应用会沿用原有方式；连接凭证验证失败时，会正确报告验证问题。

## 三个区域新增 More 菜单

![xhs-02-more-menu](/posts/2026-10-25-dsh-0.2.1-rc.3-release/assets/e9641b120b7e.png)

左侧栏、会话顶部和右侧工具栏都新增了 **More** 菜单。菜单提供两个入口：

| 菜单项 | 用途 |
| --- | --- |
| **Browse other plugins** | 打开插件列表，不会直接弹出安装窗口 |
| **Create your plugin** | 用 Creator 预设开启会话，并把入口所在区域的信息填入草稿；不会自动发送 |

窗口较窄时，放不下的会话 View 标签会收进顶部菜单；当前正在查看的标签会显示勾选。菜单目前不提供固定或排序功能。

## New Session 会复用空白会话

![xhs-03-new-session](/posts/2026-10-25-dsh-0.2.1-rc.3-release/assets/b36f82f76b45.png)

“空白会话”是已经创建、但还没有开始对话的会话，里面可能保存着尚未发送的草稿。rc.3 点击 **New Session** 时，会优先打开工作区里第一个未开始、未归档的空白会话；找不到时才新建一个。所以点 New Session 后，之前没发送的草稿仍可继续编辑。

如果指定了 Agent 预设，只会复用使用同一预设的空白会话，避免一个预设接管另一个预设的草稿。修改预设定义后，请先重启 Host，再新建会话，以便按新设置创建。

## 桌面端行为统计补充

![xhs-04-analytics](/posts/2026-10-25-dsh-0.2.1-rc.3-release/assets/51be6a515f2b.png)

桌面版增加 More 菜单操作、预设切换和 Code Work 开关的统计，并为侧栏菜单和发送按钮补充位置、会话类型等信息。自定义预设统一记为 `other`，不会上报预设名称；统计数据不包含会话内容，普通 Web 版不上报这些事件。

## 升级前后要留意

CLI 用法没有变化，也不需要额外配置。升级后主要检查两件事：

1. 如果模型列表不再自动更新，在模型设置中选择 **Restore defaults**。
2. 如果刚修改了 Agent 预设，先重启 Host，再创建新会话。
