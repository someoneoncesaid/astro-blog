DeepSeek Harness 更新到 0.2.3-alpha.2。这次整理的是 0.2.2-rc.5 以来的累计变化，重点看办公应用接入、任务进度和代码评审。

① 七个应用接进来，Office 统一用 /office
飞书、企业微信、腾讯会议和钉钉走厂商 CLI，Notion、Linear 和腾讯文档走 MCP。安装并启用对应插件后，再连接账号。以前用 /office-docx、/office-pptx、/office-xlsx 的场景，现在统一用 /office。加载技能后，渲染、格式转换和公式重算工具从模型的下一步开始可用。

② 长任务做到哪一步，可以打开时间线看
先启用实验性时间线插件，再点输入框上方的进度条，就能查看任务、阻塞原因和阶段报告。会话面板还可以看工作目录、分支和子智能体状态，侧栏会标记这一轮还没看的结果。

③ 代码评审有独立页面，变更视图可扩展
评审页可以切换「待我评审」「我创建的」「与我有关」。会话里的变更视图也支持插件扩展，图卡里放了自定义筛选、文件操作和行注解的例子。

④ 升级前留意 Node.js 和旧 PTC 脚本
alpha.2 要求 Node.js 24.x 至少为 24.22.3，或使用 26.13.1 及以上版本。Node PTC 从 alpha.1 起默认在同一个 Agent 内复用进程，顶层变量可以留给下次调用。旧脚本里的顶层 return 可以改成末尾表达式，或显式设为 per-call。

其他值得留意的变化
• 文件右键可把引用加进草稿，继续编辑后再发送。点击对话里的压缩记录，可以在右侧栏预览手动或自动生成的摘要。
• 桌面应用菜单可直接打开设置，并显示当前生效的单步快捷键。内置目录模型可以自定义推理档位，关闭后沿用目录默认档位。
• Git 仓库可作为插件源。远程 Web 支持在新设备发起配对，再由已登录设备批准。
