DeepSeek Harness 0.2.2-rc.4 发布：内容拒答不再被误报成「响应格式错误」，错误码换成专用的 CONTENT_REFUSED——失败前先报已计费用量，不重试，配了升级指南与回放快照；另修 liveshare 隧道 worker 被单实例锁结束的问题。紧接着 rc.5 把搜索默认改成跟着模型走：DeepSeek 模型会话自动使用服务端搜索（Anthropic 格式的 web_search 服务端工具），其他模型继续用 DeepSeek Search API；设置页新增「自动选择」，「DeepSeek（旧版）」改名「DeepSeek 服务端搜索」。官方价目表同页补充：自北京时间 2026-11-18 12:00 起，调用模型时触发的服务端搜索、网页抓取不再计费，仅按模型 Token 用量计费；独立 Search API / Fetch API 仍为每 1,000 次成功请求 5 元。搜索端点独立于对话，网关场景需单独配置 baseURL。两次更新都没有 CLI 或会话格式变化。
